What just happened

When A sends, the wasm node fragments + signs the message into SPORE envelopes and hands the router's forwards to the loopback transport. B's node receives them, verifies the signature, and delivers the payload. No server is involved — both nodes and the router are this page. The same Hub + transport model swaps loopback for a WebSocket, WebRTC channel, or Nostr relay to reach other devices (see the web guide).
